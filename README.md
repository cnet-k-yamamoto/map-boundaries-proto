# map-boundaries-proto

Power BI の図形マップ（Shape map）を試作するための、日本の行政区域の境界データ（TopoJSON）です。試作用の仮置きで、予告なく変更・削除することがあります。

## ファイル

| ファイル | 中身 | キー（`properties.key`） |
|---|---|---|
| `level_pref*.json` | 都道府県 | 都道府県名 |
| `level_muni*.json` | 市区町村（政令指定都市は区、浜松市は市で1つ） | 都道府県名＋市区町村名 |
| `level_region*.json` / `level_area*.json` | 市区町村をまとめた任意のグループ | 記号（`R1`〜、`A01`〜） |

ファイル名の末尾（`_kinki` など）が付いたものは、その範囲だけを切り出したものです。範囲を切り出したファイルでは、伊豆諸島・小笠原の町村を除いています。

## 出典

「国土数値情報（行政区域データ）」（国土交通省）を、スマートニュース メディア研究所が簡素化して公開したデータ（[smartnews-smri/japan-topography](https://github.com/smartnews-smri/japan-topography)、2021年1月1日時点）を基に、市区町村の統合・グループ化・切り出しの加工をして作成しました。

利用する場合は、国土数値情報の利用規約に沿って出典を表示してください。
